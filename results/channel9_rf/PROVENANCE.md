ESA-ADB Mission 2, channel_9, with a chronological 70/15/15 split. All metrics are
sample-level (each observation counted separately) and come from one run. They are not
comparable with the event-wise Mission 1 results elsewhere in this repository.

from a different run than the ones quoted in the teammate's README (0.740 s, 0.990 s,
1.172 s). The dashboard uses the file values.
